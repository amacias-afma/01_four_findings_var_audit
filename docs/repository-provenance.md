# Repository provenance — where each artefact lives

## Sources of truth

| Artefact | Location | Status |
|---|---|---|
| Manuscript prose | `paper/draft-v1.md` | **Single source of truth** |
| Root LaTeX | `main.tex` | Structure only; `\input`s the sections |
| LaTeX sections | `paper/tex/sections/*.tex` | **Generated** from the markdown — never edit by hand |
| Bibliography | `paper/tex/refs.bib` | Checked against `paper/references.md` |
| Figures | `paper/tex/figures/` | Regenerated by `scripts/refresh_paper_figures.py` |
| Results | `outputs/` | Produced by the experiment scripts; never edited by hand |

## Regeneration rule

Prose is edited only in `paper/draft-v1.md`. Afterwards:

```bash
python scripts/import_tex.py     # regenerate the LaTeX sections
latexmk -pdf main.tex            # rebuild the PDF
```

Editing a generated `.tex` file is futile: it is overwritten on the next import, and
`import_tex.py --check` fails while the two disagree.

## Why the root `references.bib` is empty

`references.bib` at the repository root is intentionally empty, with a note pointing to
`paper/tex/refs.bib`. Anything that still reads the root file fails loudly instead of silently
compiling an outdated bibliography.

## Verification commands

Run these before publishing; do not rely on remembered results.

```bash
python -m pytest -q                                   # 123 passed, 5 skipped
python scripts/refresh_paper_figures.py --check       # summaries vs. result CSVs
python scripts/import_tex.py --check                  # LaTeX up to date with the markdown
python scripts/check_bib.py                           # refs.bib vs. references.md
python -m value_at_risk.evaluation.ledger --summary   # disclosure integers
```
