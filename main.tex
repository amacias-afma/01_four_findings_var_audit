% --- The 'none' counter -----------------------------------------------------
% pandoc 3.x wraps a caption-less markdown table as
%     {\def\LTcaptype{none} \begin{longtable}...}
% which asks LaTeX for a counter named `none` that no package defines, raising
%     ! LaTeX Error: No counter 'none' defined.
% once per table — 14 errors here. Defining the counter satisfies the reference; nothing
% ever prints it, so it has no visible effect.
%
% Diagnosis worth recording, because two plausible explanations were wrong first:
%   - It is not a \captionsetup problem. Scoping the setup to [figure]/[table] made a
%     minimal test WORSE (3 errors vs 2); package options fixed the toy case and not the
%     real document.
%   - It is not distribution-specific in origin. MiKTeX 25.12 surfaced it and TeX Live had
%     also produced it once the build stopped reusing a cached PDF. It looked like a
%     MiKTeX quirk only because the earlier "clean" builds were stale.
% The cause is the pandoc version that generated paper/tex/sections/: those files carry
% `\toprule\noalign{}`, which is pandoc 3.x output, while the sandbox that first built them
% ran pandoc 2.9. Defining the counter makes the preamble work with either.
